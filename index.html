counter.v

Verilog
module counter (
    input wire clk,
    input wire rst_n,
    output reg [3:0] count
);

    always @(posedge clk or negedge rst_n) begin
        if (!rst_n)
            count <= 4'b0000;
        else
            count <= count + 1'b1;
    end

endmodule

Detailed report

This module implements a 4-bit synchronous up-counter with an active-low asynchronous reset. On every rising edge of clk, the counter increments by one unless rst_n is asserted low, in which case the count resets to zero. This is a common building block used in timers, address generators, and control sequencers — simple enough to synthesize cleanly, and a good candidate module for demonstrating the rest of the flow end to end.
